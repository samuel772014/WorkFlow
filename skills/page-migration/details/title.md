# 詳細規則：頁面標題名稱

> 對應審查區塊 `review-title`。權威來源＝`.claude/SelfFolder/SAL程式編號對照表.md` 的「功能名稱」欄（由 `SAL程式列表.xlsx` 轉出；CLAUDE.md 鐵則3）。
> **不以 dfm `Caption` 為準**（Delphi 表單 Caption 常與正式名不同），也不自行簡化/改字。

---

## 規則

1. **格式固定：`(程式代號)程式名稱`**，半形括號、括號後不空格。
   ```razor
   <PageTitle>({{FORM}}){{對照表功能名稱}}</PageTitle>
   ```
   例：`<PageTitle>(SAL001)業務人員維護</PageTitle>`
2. **程式代號＝檔名代號**（`SAL067.razor` → `(SAL067)`）。
3. **程式名稱＝對照表「功能名稱」逐字照抄**（含「計畫/計劃」「型式/形式」等用字，以對照表為準）。
4. **子視窗/元件（`SAL0XXA/B/D`，非 `@page`）不放 `PageTitle`**；其視窗標題放呼叫端 `<WindowTitle>`，內容依 Delphi 子 form Caption。
5. 對照表查無該代號 → 標【待確認】問使用者，不自行命名（鐵則4）。

### 例外：對照表一列含「／」的合併頁（2026-10-08 使用者裁決：維持現值）
一頁涵蓋「申請維護 ／ 審核確認」兩支 Delphi 程式時，**維持既有標題**，不照抄含「／」的全名。允許清單：

| 代號 | 允許標題 | 對照表原文 |
|---|---|---|
| SAL046 | 報價單申請審核維護 | 報價單申請維護 ／ 報價單審核確認 |
| SAL047 | 報價單變更維護 | 報價單變更申請維護 ／ 報價單變更審核確認 |
| SAL055 | 訂單維護 | 訂單申請維護 ／ 訂單審核確認 |
| SAL056 | 核價單維護 | 核價單申請維護 ／ 核價單審核確認 |
| SAL057 | 訂單變更 | 訂單變更申請維護 ／ 訂單變更審核確認 |
| SAL078 | 銷貨單維護 | 銷貨單申請維護 ／ 銷貨單金額審核 |

> 新頁遇到含「／」的合併列且不在上表 → 標【待確認】問使用者，不自行取名。

## 檢查方式（review-title / 交付前）

- 頁面 `<PageTitle>` 符合 `^\((SAL[0-9A-Z]+)\)(.+)$`，代號＝檔名，名稱＝對照表功能名稱。
- 例外清單內的頁面比對「允許標題」。
- 2026-10-08 實況：SAL 91 頁中 71 頁一致、6 頁屬上方例外、**14 頁與對照表不同屬程式碼待改**，清單見 `.claude/SelfFolder/review-engine/skill-optimization.md` §I。
